# BEAT SURGE: NEON FALL (비트 서지: 네온 폴)

화려한 네온 비주얼과 신스웨이브 음악을 즐길 수 있는 **수직 낙하형 4키 리듬 게임**입니다.  
위에서 내려오는 타일(단타 및 롱노트)을 판정선에 맞춰 누르고 고득점 및 콤보를 달성해 보세요!

---

## 🎮 게임 실행 방법
1. **가장 빠른 실행**: 폴더 내 `run_game.bat` 파일을 더블클릭합니다.
2. **또는**: `index.html` 파일을 크롬(Chrome), 엣지(Edge) 등 웹 브라우저로 열어주세요.
3. 화면의 **[▶ 게임 시작]** 버튼을 누르고 원하는 곡을 선택하면 즉시 플레이할 수 있습니다.

---

## ⌨️ 게임 조작 방법
- **4키 레인**: `D`, `F`, `J`, `K`
  - 레인 1: **`D`** (네온 사이언)
  - 레인 2: **`F`** (네온 마젠타)
  - 레인 3: **`J`** (네온 마젠타)
  - 레인 4: **`K`** (네온 사이언)
- **마우스 / 터치**: 스마트폰, 태블릿 또는 마우스로 레인 하단을 클릭/터치하여 플레이할 수도 있습니다.
- **일시정지**: `ESC` 키

---

## 🌟 주요 특징 및 시스템
1. **타일 종류**:
   - **단타 노트 (Tap Tile)**: 판정선에 닿을 때 정확히 키를 탭합니다.
   - **롱노트 (Hold Tile)**: 긴 빔 형태로 내려오며, 끝날 때까지 키를 누르고 있어야 연속 콤보 틱 점수가 오릅니다.
2. **자체 내장 신시사이저 음악 (Web Audio Synth)**:
   - 별도의 mp3 다운로드 없이도 브라우저의 Web Audio API를 이용해 풍부한 전자 음악(Synthwave, Trance, Eurobeat)을 실시간으로 합성 및 재생합니다.
   - 키를 칠 때마다 맑고 경쾌한 펜타토닉 타격음(Hit Sound)이 발생합니다.
3. **내장 수록곡 (3곡)**:
   - 🎵 **Neon Skyline** (128 BPM / NORMAL Lv.5) - 감미로운 신스웨이브와 하우스 비트
   - 🎵 **Starlight Velocity** (150 BPM / HARD Lv.9) - 빠른 트랜스와 다이나믹한 계단 타일
   - 🎵 **Quantum Hyperdrive** (175 BPM / EXPERT Lv.13) - 초고속 유로비트와 복합 롱노트 폭타
4. **내 음악(MP3/WAV/OGG) 자동 채보 분석 기능**:
   - 곡 선택 화면의 하단 업로드 영역에 원하는 노래 파일을 드래그앤드롭하거나 클릭하여 넣으면, **온셋(Onset) 에너지 분석 알고리즘**이 자동으로 리듬 비트를 감지하여 4레인 채보를 생성해 줍니다!
5. **게임 설정 & 옵션**:
   - **노트 낙하 배속 조절**: 1.0x ~ 5.0x (곡 선택 화면 및 설정창에서 실시간 조절)
   - **BGM 및 효과음(SFX) 개별 볼륨 조절**
   - **싱크 오프셋 (Calibration)**: 모니터나 사운드 지연에 맞춰 ±150ms 미세 조정 가능
6. **시각 효과**:
   - 타격 시 20개 이상의 네온 파티클 폭발 & 쇼크웨이브 링 이펙트
   - 키 누름 빔 라이트 및 실시간 콤보 펄스 애니메이션
   - 판정 등급: `PERFECT`, `GREAT`, `GOOD`, `MISS`
   - 최종 랭크: `SSS`, `SS`, `S`, `A`, `B`, `C`, `F`
